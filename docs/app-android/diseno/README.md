# Diseño de la app (Android)

Copia del diseño hecho en claude.ai (artefacto "Design", privado). Cada archivo `.dc.html` es una pantalla
de 390 × 844: Inicio, Cargar (gasto, ingreso y transferencia), Movimientos, Próximos, Explorar (Más),
Ajustes, Ayuda, Bienvenida, Ingresar, Registro, Verificar y Recuperar. `canvas.json` ordena las pantallas.

Es la referencia visual de lo que está construido en `src/app/movil`. Para verlo con sus animaciones,
abrir el artefacto en claude.ai.
